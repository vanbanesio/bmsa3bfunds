# bmsa3bfunds
BSMA 3B CLASS FUNDS

## Deploy on Netlify

Connect this repository to Netlify and deploy from the repository root. `netlify.toml` configures the page, the `/api/*` function, and the root-page rewrite. Netlify Blobs stores receipt files and metadata.

Before deploying, add `ADMIN_PASSCODE` under **Project configuration → Environment variables** in Netlify. Use the passcode you chose; do not put it in this repository. Redeploy after setting it.

Receipt uploads support JPEG, PNG, WebP, and PDF files up to 4 MB.
